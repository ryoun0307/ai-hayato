# 予想の手順書（案・ユーザーの OK 待ち）

過去レースで「この手順で予想すると当たるか」を確かめるための手順です。
予想するのは Sonnet（Claude Code のこのセッション。Web 検索なし・料金ゼロ）。

## 0. 守ること（結果を知らない状態）
- 読んでいいのは `data/question/` のファイルだけ。`data/answer/`（結果・払戻金）は予想が終わるまで開かない。
- 予想は1レースずつ。ほかのレースの結果は見ない。
- Claude 自身はこの時期（2026年10〜11月）のレース結果を知らない（学習したのは2026年6月ごろまで）。
  もし「このレースの勝ち馬を知っている」と感じたら、そのレースは予想から外して報告する。

## 1. 渡すデータ（`data/question/日付_場_R.json`）
| | 仮予想（前日夜の想定） | 最終予想（発走30分前の想定） |
|---|---|---|
| レース名・クラス・距離・芝/ダート・回り・発走時刻 | ○ | ○ |
| 馬番・枠・馬名・性齢・斤量・騎手・調教師 | ○ | ○ |
| 血統（父・母・母の父） | ○ | ○ |
| 各馬の過去4走（そのレース日より前だけ） | ○ | ○ |
| 当日の天候・馬場状態 | × | ○ |
| 馬体重（増減）・単勝人気 | × | ○ |

※過去4走の馬場・着順・タイム・頭数・人気・騎手・斤量・馬体重・勝ち馬は入っています。通過順位・上がりは入っていません（成績ページに無いため）。
※当時のオッズの数字は無いので、最終予想では「人気の順番」を使います。

## 2. 各馬を5段階で評価する（5＝とても良い、3＝ふつう、1＝悪い）
1. 近走の成績（着順・人気との比較・相手の強さ・クラス）
2. 距離の向き不向き（過去の距離、血統）
3. コース・馬場の向き不向き（芝/ダート、競馬場、重い馬場など。仮予想では馬場は「良」と仮定）
4. 騎手（騎手の腕、乗り替わり）
5. 休み明け（前走からの間隔。長い休みは減点）
6. 枠（内か外か。コースとの相性）
7. 展開（逃げ・先行が多いか。有利・不利）
8. 馬体重の増減（最終予想のみ。極端な増減は減点）

## 3. 勝つ見込み（%）を出す
- 項目ごとの評価を、近走を重めにして合計点にする（近走×3、距離・コース馬場・展開×2、ほか×1）。
- 合計点が高い馬ほど大きい%になるよう割り振り、レース全体で合計100%にする。
- 最終予想では、人気の順番も見比べる。人気と大きく違うときは、理由をひとこと書く。

## 4. 印と自信度
- ◎（本命）・○・▲・△・△（計5頭）を、勝つ見込みの高い順に付ける。
- 自信度：A（◎が飛び抜けている）／B（ふつう）／C（混戦で自信がない）。

## 5. 買い目（1点100円）
- 単勝：◎ 1点　／　複勝：◎ 1点
- 馬連ボックス：◎○▲と1頭目の△の4頭、6点
- 馬連流し：◎から ○▲△△ へ、4点
- 3連単：◎1着固定、2・3着は ○▲△△ から、12点
- 合計 1レース 25点＝2,500円。

## 6. 記録（`predictions/日付_場_R_仮.json` / `_最終.json`）
印と順位、各馬の勝つ見込み（%）、項目ごとの評価、自信度、買い目、予想の理由（3行以内）を保存する。
項目ごとの評価を残すのは、外れたとき「どの項目が当てにならなかったか」をあとで調べるため。

## 7. 答え合わせ（予想がすべて終わってから）
- `data/answer/` の払戻金で、券種ごとの「払った金額・戻った金額・回収率」と的中率を出す。
- 比較：「1番人気から順に同じ組み方で買った場合」／仮予想と最終予想／自信度ごとの成績。
- 回収率が100%を超えなくても、そのまま正直に報告する。150〜200レースでは運の影響が大きいことも伝える。
